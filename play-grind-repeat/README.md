# PLAY / GRIND / REPEAT

Concept site for a fictional street basketball championship at the OVO Hydro, Glasgow (14–16 May 2027).

`index.html` is fully self-contained — images, fonts, three.js and Lenis are bundled inside. No build step.

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Push this folder to a repo.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `root`.
3. The site goes live at `https://<user>.github.io/<repo>/`.

## Features
- Scroll-driven cinematic hero (river → doors → tunnel → court)
- Real-time 3D basketball (three.js) that follows the scroll and sinks the last shot
- Horizontal weekend schedule, player bios, 16 team rosters, tickets
- Responsive down to phone widths

Images generated with Higgsfield. All teams, players and stats are fictional.
